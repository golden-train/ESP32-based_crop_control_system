## 三、主要函数调用链

### 3.1 启动流程

```
main()
 ├─ ErrorHandler_init()
 ├─ ensureWsa()
 ├─ SensorDisplay 构造（创建 1280×800 窗口、加载字体）
 ├─ CreateThread(dataThreadFunc)  ← 数据线程
 └─ UI 主循环:
      ├─ display.processEvents()  ← 处理鼠标点击 / 窗口事件
      ├─ display.render()         ← 绘制当前页面
      ├─ processUiCommands()      ← 消费手动指令队列 → sendCmdRaw()
      └─ Sleep(16ms)
```

### 3.2 数据线程流程

```
dataThreadFunc (data_source.cpp)
 └─ runServerMode()
      └─ 每分钟执行一次:
           ├─ toIsoString() —— 计算查询时间范围
           ├─ ServerClient_connect() —— 连接 TCP 服务端
           ├─ ServerClient_fetchLogs() —— 拉取日志
           ├─ parseLogLine() —— 逐行解析 SensorData
           │    └─ tryParseSensorData()
           │         └─ extractNumbers()
           ├─ display->setHistory() —— 更新图表
           ├─ display->updateData() —— 更新实时数据
           ├─ AnalysisRules_feedDataPoint() —— 存入分析数据点
           ├─ AnalysisRules_checkUrgent() —— 执行分析
           │    ├─ detectRisingTrend() —— 温度趋势检测
           │    │    └─ ringPush() / ringAt() —— 环形缓冲区操作
           │    ├─ PPFD 计算（lux × parCoeff）
           │    ├─ 温度阈值判断（> 35°C → 蜂鸣器 '3'）
           │    └─ 土壤湿度判断 + 温度互锁（< 20% → '4', > 65% → '6'）
           ├─ sendCmdRaw() —— 发送控制指令到服务端
           ├─ display->applyCommand() —— 同步 UI 执行器状态
           ├─ display->setAnalysisData() —— 推送分析数据到 UI
           └─ Sleep(100ms)
```

### 3.3 PPFD/DLI 计算链

```
AnalysisRules_feedDataPoint()
  └─ ppfd = lightIntensity × config.parCoeff
  └─ ppfdSum += ppfd

AnalysisRules_avgPpfd()
  └─ return ppfdSum / dataPointCount

AnalysisRules_currentDli()
  └─ avgPpfd × (dataPointCount × 5min) × 3600 / 1e6
```

### 3.4 手动指令流程

```
UI 线程:
  processUiCommands()
    ├─ SensorDisplay::popCommand() —— 出队
    ├─ sendCmdRaw("CMD:x") —— TCP 发送
    ├─ display->applyCommand(cmd) —— 更新本地状态
    ├─ (c == 'T') → fetchLatestRaw() → tryParseSensorData() → processData()
    └─ logMessage()

数据线程:
  processManualCommands()
    ├─ SensorDisplay::popCommand()
    ├─ (c == '8') → AnalysisRules_clearAlarm()
    ├─ display->applyCommand(c)
    └─ logMessage()
```

### 3.5 分析报警链

```
AnalysisRules_checkUrgent()
  ├─ detectRisingTrend() → 连续上升 → cmd '3'（蜂鸣器）
  ├─ PPFD < parMin → cmd '1'（开补光）
  ├─ PPFD > parMax → cmd '5'（关补光）
  ├─ temp > 35°C → cmd '3'（蜂鸣器），设置 tempAlarmActive
  ├─ soil < 20% && !tempAlarmActive → cmd '4'（开灌溉）
  └─ soil > 65% && irrigating → cmd '6'（关灌溉）+ accumulateWaterUsage()
```

## 五、模块职责汇总

| 模块 | 文件 | 职责 | 线程 |
|------|------|------|------|
| 主入口 | system.cpp | 初始化、UI 主循环、清理 | 主线程 |
| 公共工具 | system_utils | 全局变量、TCP 收发、日志、手动指令处理 | 主/数据 |
| 数据源调度 | data_source | 数据线程入口、服务端模式运行 | 数据线程 |
| 分析引擎 | analysis_rules | 数据点存储、趋势检测、PAR/DLI 计算、灌溉决策 | 数据线程 |
| TCP 客户端 | server_client | 长连接 TCP 通信、日志查询、指令发送 | 多线程 |
| 数据解析 | number_parser | 提取数字、解析 SensorData、日志行解析 | 任意 |
| UI 显示 | sensor_display | SFML 窗口、仪表盘、图表、控制面板、建议页 | 主线程 |
| 错误处理 | error_handler | 错误队列、异常数据日志记录 | 独立线程 |
| 串口读取 | serial_reader | Windows 串口操作（当前未使用） | — |
| 串口分发 | serial_dispatcher | 串口后台读取线程（当前未使用） | — |
| 数据结构 | sensor_data | SensorData 结构体定义 | — |


## 七、环形缓冲区使用

| 位置 | 容量 | 数据 | 用途 |
|------|------|------|------|
| analysis_rules → tempHistory | 500 | 温度 (°C) | 滑动窗口统计均值、趋势检测 |
| analysis_rules → soilHistory | 500 | 土壤湿度 (%) | 滑动窗口统计均值 |
| analysis_rules → lightHistory | 500 | 光照 (lux) | 滑动窗口统计均值 |
| sensor_display → m_tempHistory | 300 | 温度 (°C) | 折线图绘制 |
| sensor_display → m_soilHistory | 300 | 土壤湿度 (%) | 折线图绘制 |
| sensor_display → m_lightHistory | 300 | 光照 (lux) | 折线图绘制 |
| error_handler → s_queue | 64 | 错误行文本 | 异常数据缓存 |
| serial_dispatcher → queue | 16 | 串口行文本 | 串口响应队列（当前未用） |
