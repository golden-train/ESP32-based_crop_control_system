# ESP32 传感器监控系统 — 技术文档

## 1. 项目概述

从 ESP32 开发板读取环境温度、湿度、土壤湿度、光照强度四个传感器数据，通过 **SFML** 图形界面提供实时仪表盘、历史趋势分析与手动控制的桌面监控程序。

**主要特性：**
- 实时仪表盘：4 个柱状仪表 + 折线趋势图
- 数据分析页：2×2 大图表 + 最小/最大/平均统计
- 手动控制页：5 个指令按钮，向 ESP32 发送控制命令
- 串口/演示双模式：未接开发板自动使用模拟数据
- 多线程架构：主线程渲染 UI，独立线程采集数据
- 数据日志：带时间戳的文本日志文件

## 3. 模块详解

### 3.1 `sensor_data.hpp` — 传感器数据结构

```cpp
struct SensorData
{
    double temperature = 0.0;    // 环境温度 (°C)
    double humidity = 0.0;       // 环境湿度 (%)
    double soilMoisture = 0.0;   // 土壤湿度 (%)
    double lightIntensity = 0.0; // 光照强度 (lux)
};
```

**用途：** 在采集线程和 UI 线程之间传递一帧传感器数值。

---

### 3.2 `serial_reader.hpp/.cpp` — 串口读写

封装 Windows 串口 API（`CreateFile` / `ReadFile` / `WriteFile`）。

| 函数 | 说明 | 调用方式 |
|------|------|----------|
| `bool open(portName, baudRate)` | 打开串口 | `reader.open("COM6", 115200)` |
| `void close()` | 关闭串口 | `reader.close()` |
| `HANDLE nativeHandle()` | 获取句柄 | 传给 SerialDispatcher |
| `bool readLine(string &out)` | 读一行 | `reader.readLine(line)` |
| `bool writeText(text, outError)` | 发送文本 | `reader.writeText("1", err)` |

**串口参数：** COM6, 115200 baud, 8-N-1, 无超时（立即返回）。

### 3.3 `serial_dispatcher.hpp/.cpp` — 串口分发

在后台线程持续读取串口，根据当前状态分发数据：

| 函数 | 说明 |
|------|------|
| `void start(handle, onError)` | 启动后台读取线程 |
| `void stop()` | 停止线程并等待退出 |
| `void expectResponse()` | 标记下一行是正常响应 |
| `string waitResponse()` | 阻塞等待正常响应 |

**分发逻辑：**
- `m_expectingResponse == true` → 放入主队列，主线程消费
- `m_expectingResponse == false` → 调用 errorCallback（推入 `g_errorQueue`）

#### 核心函数

| 函数 | 说明 |
|------|------|
| `logMessage(msg)` | 输出到控制台 + SFML 日志区 |
| `processData(data)` | 控制台输出 + 写日志 + 更新 SFML 仪表盘 |
| `tryParseSensorData(line, outData)` | 解析一行文本到 SensorData |

| `main()` | 入口：初始化 → 启动线程 → SFML 主循环 → 清理 |

#### `main()` 完整流程

```cpp
int main()
{
    // 1. 设置控制台 UTF-8
    SetConsoleOutputCP(CP_UTF8);

    // 2. 准备日志目录
    CreateDirectoryA("temp");
    ofstream("temp/sensor_log.txt", trunc);

    // 3. 创建 SFML 窗口
    SensorDisplay display;
    g_display = &display;

    // 4. 打开串口 / 或进演示模式
    SerialReader reader;
    bool realMode = reader.open("COM6", 115200);

    // 5. 数据线程：采集 + 解析 + 分析
    thread dataThread([realMode, &reader]() {
        if (realMode) runRealMode(reader);
        else          runDemoMode();
    });

    // 6. 主线程：SFML 事件循环 + 渲染
    while (display.isOpen() && g_running) {
        display.processEvents();
        display.render();
        this_thread::sleep_for(16ms);  // ~60fps
    }

    // 7. 通知退出 + 等待线程
    g_running = false;
    dataThread.join();
    reader.close();
    return 0;
}
```

#### `runRealMode()` 采集循环

```
while (g_running) {
    1. writeText("0")              ← 发送触发指令
    2. dispatcher.expectResponse() ← 标记正常响应
    3. line = dispatcher.waitResponse() ← 等待串口行
    4. tryParseSensorData(line)    ← 解析为 SensorData
    5. processData(data)           ← 输出 + 日志 + UI
    6. readLatestFromLog()         ← 读最新数据
    7. AnalysisRules.observe()     ← 异常检测
    8. → 异常 → writeText(cmd)     ← 发送控制指令
    9. sleep(1s)
    10. popCommand(manualCmd)       ← 检查手动指令
        → writeText(manualCmd)
}
```

#### `runDemoMode()` 模拟循环

```
while (g_running) {
    1. SimulatedSensor::generate()  ← 生成模拟数据
    2. processData(data)            ← 输出 + 日志 + UI
    3. AnalysisRules.observe()      ← 异常检测
    4. → 异常 → logMessage(cmd)    ← 仅打日志（无串口）
    5. 每 5 次推送一条模拟异常
    6. sleep(1s)
    7. popCommand(manualCmd)        ← 检查手动指令
        → logMessage("演示模式")
}
```

## 5. 数据流

### 5.1 数据格式

ESP32 每行通过串口发送 4 个空格分隔的数字：

```
25.3 55.1 42.7 813
↑     ↑    ↑    ↑
温度  湿度 土壤  光照
```

### 5.2 数据流向

```
ESP32/SimulatedSensor
    │
    ▼
tryParseSensorData() → SensorData.temperature, .humidity, .soilMoisture, .lightIntensity
    │
    ├─→ processData()
    │      ├─→ std::cout（控制台）
    │      ├─→ DataLogger::log()（temp/sensor_log.txt）
    │      └─→ SensorDisplay::updateData()（SFML 仪表盘）
    │
    └─→ readLatestFromLog()
           └─→ AnalysisRules::observe()
                  ├─→ 正常 → prevAnomaly 取消标记
                  └─→ 异常 → writeText(cmd) → ESP32 执行器
```

### 5.3 错误数据流

```
ESP32 自发上报 → SerialDispatcher readerLoop
    │ m_expectingResponse == false
    ├─→ errorCallback(line)
    │      └─→ g_errorQueue.push(line)
    │             └─→ errorHandlerThread
    │                    ├─→ tryParseSensorData → 显示 + 写日志
    │                    └─→ logMessage("[异常上报] " + line)
```

## 8. 常见问题

**Q: SFML 中文显示乱码？**
A: 确保使用 `L"中文"` 宽字符串字面量，添加编译标志 `-finput-charset=UTF-8 -fexec-charset=UTF-8`，字体使用 `msyh.ttc`。

**Q: 串口打不开？**
A: 检查是否已插入 ESP32，设备管理器中确认 COM6 是否存在。程序会自动降级为演示模式。

**Q: 日志文件在哪？**
A: `src/output/temp/sensor_log.txt`（相对于 exe 工作目录）。
