# ESP32 传感器监控系统 - 架构改造任务书

> 创建日期：2026-05-14
> 对应版本：system 2.1.0

---

## 一、改造目标

```
改造前：
ESP32 ──(固定1s上报)──→ MQTT Broker ──(PC直连订阅)──→ PC实时分析

改造后：
ESP32 ──MQTT──→ Broker ──→ 服务端日志服务(TCP) ←── PC客户端
  ↑                     ↓ (日志文件 7天轮转)
  └────── esp32/cmd ────┘
```

### 核心变更

| 项目 | 改造前 | 改造后 |
|------|--------|--------|
| ESP32 上报频率 | 固定1秒 | 默认5分钟，实时模式2秒 |
| 异常上报 | 每3秒 | 不受限，即时上报 |
| 服务端 | 仅 MQTT Broker | Broker + Python 日志服务 |
| 数据持久化 | 无 | 7天轮转日志文件 |
| PC 数据来源 | 直接订阅 MQTT | 连接服务端 TCP 接口 |
| 演示模式 | 存在 | **彻底删除** |
| 串口模式 | 存在 | **保留** |
| 智能分析 | 实时分析 | 基于服务端日志触发分析 |
| 通讯协议 | MQTT 直连 | TCP 文本协议(PC↔服务端) |

## 三、TCP 协议定义（PC ↔ 服务端）

### PC → 服务端

| 命令 | 格式 | 说明 |
|------|------|------|
| 注册连接 | `CONNECT\n` | PC 上线注册 |
| 断开 | `DISCONNECT\n` | PC 下线 |
| 心跳 | `PING\n` | 每10秒 |
| 请求日志 | `GET_LOGS begin=2026-05-14T00:00:00 end=2026-05-14T23:59:59\n` | 按时间范围查询 |
| 请求异常 | `GET_ANOMALIES begin=... end=...\n` | 查询异常数据 |
| 发送命令 | `CMD:4\n` | 发送控制指令到 ESP32 |

### 服务端 → PC

| 消息 | 格式 | 说明 |
|------|------|------|
| 注册成功 | `CONNECTED\n` | 确认上线 |
| 实时数据 | `DATA:25.3 55.1 42.0 813\n` | 实时转发传感器数据 |
| 异常数据 | `ALERT:!25.3 55.1 42.0 813\n` | 异常上报转发 |
| 日志结果 | `LOGS_BEGIN\n...\nLOGS_END\n` | 历史日志查询结果 |
| PONG | `PONG\n` | 心跳响应 |

## 四、架构数据流

```
                      NORMAL: 每5min
     ┌──────────┐  ──────────────→  ┌──────────────┐
     │  ESP32   │   REALTIME: 每2s  │ MQTT Broker  │
     │ (传感器)  │  ─────────────→  │ 8.137.48.225 │
     │ (执行器)  │  ←─────────────  │  port 1883   │
     └──────────┘    esp32/cmd      └──────┬───────┘
                                           │ 订阅 esp32/data
                                           │ esp32/alert
                                           ▼
                                    ┌──────────────┐
                                    │ 服务端日志服务  │
                                    │ (Python)      │
                                    │ port 9090     │
                                    ├──────────────┤
                                    │ 日志文件(7天)  │
                                    └──────┬───────┘
                                           │ TCP 协议
                                           ▼
                                    ┌──────────────┐
                                    │  PC 客户端    │
                                    │ (system.exe)  │
                                    ├──────────────┤
                                    │ 实时显示       │
                                    │ 分析(读日志)    │
                                    │ 命令下发       │
                                    └──────────────┘
```

---

## 五、回退方案

- 服务端不可用：PC 降级为**MQTT 直连模式**（订阅 `esp32/data` + `esp32/alert`）
- MQTT 不可用：降级为**串口 COM6 模式**
- 串口不可用：**程序退出**（演示模式已删除）
