# ESP32 传感器监控系统 — 技术文档

## 1. 项目概述

从 ESP32 开发板读取环境温度、湿度、土壤湿度、光照强度四个传感器数据，通过 **SFML** 图形界面提供实时仪表盘、历史趋势分析与手动控制的桌面监控程序。

**语言风格：** 除 SFML 图形界面外全部使用 C 语言风格编写（Windows API + C 标准库）。

**主要特性：**
- 实时仪表盘：3 个柱状仪表 + 折线趋势图（温度、土壤湿度、光照）
- 数据分析页：3 图表横排 + 最小/最大/平均统计
- 智能建议页：基于传感器数据的操作建议
- 手动控制页：4 个指令按钮 + PAR/用水量/报警面板
- 多线程架构：主线程渲染 UI，独立线程采集数据，错误处理线程
- 数据源自动降级：服务端 TCP → MQTT → 串口直连

## 3. API 参考

### 3.1 `sensor_data.hpp` — 传感器数据结构

```c
struct SensorData
{
    double temperature;     // 环境温度 (°C)
    double humidity;        // 环境湿度 (%)
    double soilMoisture;    // 土壤湿度 (%)
    double lightIntensity;  // 光照强度 (lux)
};
```

纯数据结构，在采集线程和 UI 线程之间传递一帧传感器数值。跨线程直接拷贝，无需互斥锁（一次性写操作）。

### 3.2 `number_parser.hpp/.cpp` — 数字提取

```c
// 从字符串中提取所有浮点数，返回成功提取个数
// "ERR_TEMP_HIGH 38.5 60.0 42.0 800" → 提取 4 个
int extractNumbers(const char* line, double* out, int maxCount);
```

**参数：**
- `line`：输入字符串
- `out`：输出数组
- `maxCount`：最多提取个数

**返回值：** 实际提取的数值个数

**实现：** 逐字符扫描，遇到数字/小数点/负号时累积，遇到分隔符时调用 `strtod` 转换。支持整数和浮点数，忽略非数字前缀。

### 3.3 `serial_reader.hpp/.cpp` — 串口读写

封装 Windows 串口 API（`CreateFile` / `ReadFile` / `WriteFile`）。

```c
typedef struct {
    HANDLE handle;           // 串口句柄
    char   buffer[1024];     // 行接收缓冲区
    int    bufferLen;        // 缓冲区当前长度
} SerialReader;

void SerialReader_init(SerialReader* sr);
int  SerialReader_open(SerialReader* sr, const char* portName, int baudRate);
void SerialReader_close(SerialReader* sr);
int  SerialReader_isOpen(const SerialReader* sr);
HANDLE SerialReader_nativeHandle(const SerialReader* sr);
int  SerialReader_readLine(SerialReader* sr, char* outLine, int maxLen);
int  SerialReader_writeText(SerialReader* sr, const char* text, int* outError);
```

**返回值约定：** 所有返回 `int` 的函数遵循 1=成功/真, 0=失败/假 的约定。

### 3.4 `serial_dispatcher.hpp/.cpp` — 串口分发

在后台线程持续读取串口，根据当前状态分发数据到正常响应队列或错误回调。

```c
#define DISPATCHER_QUEUE_SIZE 16
#define LINE_MAX 512

typedef void (*ErrorCallback)(const char* line, void* context);

typedef struct {
    char queue[DISPATCHER_QUEUE_SIZE][LINE_MAX];
    int  queueHead, queueTail, queueCount;
    CRITICAL_SECTION mutex;
    CONDITION_VARIABLE cv;
    volatile LONG expectingResponse;
    volatile LONG running;
    HANDLE   readerThread;
    HANDLE   serialHandle;
    ErrorCallback errorCb;
    void*    errorCtx;
} SerialDispatcher;

void SerialDispatcher_init(SerialDispatcher* disp);
void SerialDispatcher_start(SerialDispatcher* disp, HANDLE serialHandle,
                            ErrorCallback onError, void* context);
void SerialDispatcher_stop(SerialDispatcher* disp);
void SerialDispatcher_expectResponse(SerialDispatcher* disp);
void SerialDispatcher_clearExpectResponse(SerialDispatcher* disp);
int  SerialDispatcher_waitResponse(SerialDispatcher* disp, int timeoutMs,
                                   char* outLine, int maxLen);
```

**分发逻辑：**
- `expectingResponse == 1` → 放入主队列，主线程消费
- `expectingResponse == 0` → 调用 `errorCb(line, errorCtx)`

**调用顺序：**
```c
dispatcher.expectResponse();            // 先标记（防竞态）
SerialReader_writeText(reader, "0", &err);  // 再发触发指令
int got = SerialDispatcher_waitResponse(&dispatcher, 3000, line, LINE_MAX);
```

### 3.5 `analysis_rules.hpp/.cpp` — 规则分析

```c
// 分析配置
typedef struct {
    double growingArea;     // 种植面积 (m²)
    double pumpFlowRate;    // 水泵流量 (L/min)
    double parCoeff;        // lux → PPFD 转换系数
    double parMin;          // PAR 不足阈值 (μmol/m²/s)
    double parMax;          // PAR 充足阈值 (μmol/m²/s)
} AnalysisConfig;

// 环形缓冲区（替代 std::deque）
#define RING_MAX 500
typedef struct {
    double data[RING_MAX];
    int head, tail, count;
} RingBuffer;

// 规则分析器
typedef struct {
    RingBuffer tempHistory, soilHistory, lightHistory;
    int  risingCount, trendAlarmActive, trendAlarmSent;
    double ppfdSum, lightSum;
    int  dataPointCount;
    int  irrigating;
    DWORD64 irrigateStartMs;
    double totalWaterUsed;
    int  tempAlarmActive, tempAlarmSent;
    AnalysisConfig config;
    CRITICAL_SECTION configMutex;
} AnalysisRules;

void AnalysisRules_init(AnalysisRules* rules);
void AnalysisRules_feedDataPoint(AnalysisRules* rules, const SensorData* data);
int  AnalysisRules_checkUrgent(AnalysisRules* rules, char* cmds, int maxCmds);
void AnalysisRules_clearAlarm(AnalysisRules* rules);
void AnalysisRules_updateConfig(AnalysisRules* rules, const AnalysisConfig* cfg);
AnalysisConfig AnalysisRules_getConfig(const AnalysisRules* rules);
// + 多个状态查询函数（详见头文件）
```

**阈值表：**

| 条件 | 动作 | 指令 |
|------|------|------|
| 土壤湿度 < 30% 且 无温度报警 | 开启灌溉 | `'4'` |
| 土壤湿度 > 65% 且 正在灌溉 | 关闭灌溉 + 计算用水量 | `'6'` |
| 温度 > 35°C | 蜂鸣器 + 禁止灌溉 | `'3'` |
| 温度持续上升（趋势检测 3 次） | 蜂鸣器 | `'3'` |
| PAR 不足（< 配置值） | 开补光 | `'1'` |
| PAR 充足（> 配置值） | 关补光 | `'5'` |
| 手动清除报警 | 仅关蜂鸣器 | `'8'` |
| 关闭所有 | 全部关闭 | `'9'` |

**用水量计算：**
```
水泵流量: 2.0 L/min（占位值，可配置）
用水量 = 流量 × (停止时间 - 开始时间) / 60
```

## 5. 常见问题

**Q: 编译报错 `snprintf` 未声明？**
A: 需要包含 `<stdio.h>`。部分 MinGW 版本对 C 头文件的 `snprintf` 支持不同，确保 `#include <stdio.h>` 在源文件顶部。

**Q: 编译报 `winsock2.h` 必须在 `windows.h` 之前？**
A: 在 `system.cpp` 和 `server_client.cpp` 中，`#define WIN32_LEAN_AND_MEAN` 和 `#include <winsock2.h>` 必须在 `<windows.h>` 之前。

**Q: SFML 中文显示乱码？**
A: 确保字体加载成功。控制台输出 `[显示] 字体 XXX`。使用编译标志 `-finput-charset=UTF-8 -fexec-charset=UTF-8`。


**Q: 服务端无法连接？**
A: 检查网络连通性。
