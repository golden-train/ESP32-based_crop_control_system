# LED 库函数说明

## 初始化

```cpp
Led_start();
```

- 必须放在 `setup()` 中调用
- 初始化 R(21) / G(19) / B(18) 三个引脚为输出，默认低电平

---

## 闪烁控制

```cpp
blink_led(引脚, 亮多久ms, 灭多久ms, 闪烁次数);
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `引脚` | `int` | `LED_R` / `LED_G` / `LED_B` |
| `亮多久ms` | `unsigned long` | 每次点亮持续毫秒数 |
| `灭多久ms` | `unsigned long` | 每次熄灭持续毫秒数 |
| `闪烁次数` | `int` | 亮→灭计 1 次，完成后自动熄灭。传 `-1` 表示无限闪烁 |

**调用一次即生效**，后台自动处理，不需要在 `loop()` 中轮询。

---

## 引脚宏

```cpp
LED_R  // GPIO 21
LED_G  // GPIO 19
LED_B  // GPIO 18
```

---

## 完整示例

```cpp
#include "LED.h"
#include <Arduino.h>

void setup()
{
  Serial.begin(115200);
  Led_start();

  blink_led(LED_B, 100, 900, -1);  // 蓝灯无限慢闪
}

void loop()
{
  // 无事可做 —— 闪烁由后台自动完成
}
```

# 串口命令协议（ESP32 ⇄ PC）

## 引脚分配

| 外设 | 引脚 | 说明 |
|------|------|------|
| DHT11 | GPIO 16 | 温湿度传感器 |
| 光敏传感器 (AO) | GPIO 35 | 光照强度 |
| 土壤湿度传感器 | GPIO 34 | 土壤湿度 |
| LED_R | GPIO 21 | RGB 红灯 |
| LED_G | GPIO 19 | RGB 绿灯 |
| LED_B | GPIO 18 | RGB 蓝灯 |
| 额外指示灯 | GPIO 23 | 光照异常时亮起 |
| 水泵 | GPIO 22 | 低电平触发 |
| 蜂鸣器 | GPIO 26 | 高电平触发 |

## PC → ESP32 指令

| 指令 | 含义 | ESP32 响应 |
|------|------|-----------|
| `'0'` | 读取传感器 | 采集并返回一行数据 `温度 湿度 土壤% 光照%` |
| `'1'` | 光照异常 | 开 GPIO 23 + 红灯慢闪 3 次 |
| `'2'` | 湿度异常 | 开 水泵 + 蓝灯闪 3 次 |
| `'3'` | 温度异常 | 开 蜂鸣器 + 红灯快闪 5 次 |
| `'4'` | 土壤异常 | 开 水泵 + 红灯急促闪 3 次 |
| `'9'` | 恢复正常 | 关闭所有执行器（灯、水泵、蜂鸣器） |

## ESP32 → PC 数据格式

```
温度(°C) 湿度(%) 土壤(%) 光照(%)
```

示例：
```
24.5 60.3 45.0 72.0
```

## PC 端工作流程

1. 每 **1 秒** 发送 `'0'` 触发采集
2. 解析返回数据，检查阈值
3. 数据异常 → 发送对应指令 `'1'`~`'4'`
4. 数据恢复正常 → 发送 `'9'` 关闭执行器

## 阈值定义（PC 端 `analysis_rules.cpp`）

| 传感器 | 合理范围 |
|--------|---------|
| 温度 | 0 ~ 45 °C |
| 湿度 | 10 ~ 90 % |
| 土壤湿度 | 10 ~ 90 % |
| 光照强度 | 5 ~ 95 |
